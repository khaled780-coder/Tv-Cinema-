# 📺 القنوات الفضائية

نسخة جاهزة للرفع إلى GitHub Pages.

## المميزات
- واجهة عربية RTL.
- الدول في شريط أفقي.
- قنوات حسب الدولة.
- تشغيل HLS عبر HLS.js.
- زر البث الرسمي لـ Rotana عند فشل البث.
- PWA قابلة للتثبيت على الهاتف.

## النشر
أنشئ Repository على GitHub، ارفع الملفات، ثم:
Settings → Pages → Deploy from branch → main → /(root).

ملاحظة: القنوات مصدرها IPTV-org وقد تتغير أو تتوقف بعض الروابط.
